How to use
  1. Export: pick the project type and what to export, tick the outputs (Master, Social, Review pack), press Export.
  2. Media Encoder renders. With the panel open, each file is checked on QC as soon as it is finished, with a Mac notification when all are done. Social and Review pack are made from the master after it passes.
  3. QC: click a file for details. A problem? Go to problem jumps to it in the timeline. Re-export only that file; it is checked again.
  4. Deliver: only passed files go to Drive. Asana and Slack are prepared for Claude; you confirm first.
Colour grading export: one file per enabled V1 clip, 4K, named after the clip, 1-frame clean edge. Normal export: Whole sequence = one file per ticked sequence; Clips by cuts = the longest layer (background, BGM, an adjustment layer named “Clip 1”) marks each video; Markers = sequence markers named “Clip …” start a video that runs to the next “Clip …” or “End” marker (a marker with a duration is its own range).
