Workflow
  1. Finish the cut and grade in UAI Luma Cut.
  2. Check the export folder (the client's Final Output by default).
  3. Export: one Media Encoder job per enabled V1 clip, file named after the clip.
  4. Verify files when encoding is done: codec, frame size and size cap are read from each file.
Normal export (Project type): any edit project. Whole sequence = one file per ticked sequence, the full timeline. Clips by cuts = several videos edited in one sequence: the longest layer (background, BGM, an adjustment layer named "Clip 1"…) marks each video, everything inside it belongs to it. Files: Sequence.mp4 or Sequence_Clip01.mp4. Nested sequences start unticked.

Bitrate is set per clip from its length so every file stays under the size cap (2 GB = 2,000,000,000 bytes). Frames are scaled, never stretched. Media Encoder renders from the original files even while Premiere shows proxies, so 8K footage edited on proxies still exports at full quality.
