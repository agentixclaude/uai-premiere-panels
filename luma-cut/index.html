Good to know
  • Confirmed reviews are remembered (~/UAI Luma Cut/grade_memory.jsonl) and read by Claude on the next client.
  • Cut scope: All sequences rebuilds the Sequences bin. Current sequence and Selected clip re-cut in place, so grades already on the clips stay.
  • A file named like CAM2-4309 (1).MP4 is only skipped when the original is in the same folder.
  • Save grade sample (Review) keeps a finished grade + image in ~/UAI Luma Cut/grade_samples.jsonl; Claude matches it on later clients.
  • S-log columns are set on the Project panel by themselves when a client project opens. Sorting is one click: Video Info header, arrow down.
